This repo contains the raw data for Exp1 and Exp2 directly downloaded from PCIbex:

* raw\_data.csv (Exp1)
* raw\_data\_exp2.csv (Exp2)



The data preprocessing scripts read in these files and output formatted data files in long format suitable for analysis

* folder "cleaned\_data\_Exp1" for Exp1
* folder "cleaned\_data\_Exp2" for Exp2



The data processing scripts are inside the two cleaned data folders

* mouse\_analysis.R (Exp1)
* mouse\_analysis\_exp2.R (Exp2)



The regression outputs are stored as text files inside each experiment's folder.



The generated plots are inside the "Plots" folder.



\*\* The "mouse\_trajectories.csv" file (in folder "cleaned\_data\_Exp1" generated by data\_preprocessing.R is too large and exceeds the file size limit of GitHub. So it is stored as a zip file instead. Please regenerate the file using the preprocessing script, or unzip the file before running the mouse\_analysis.R script. \*\*
